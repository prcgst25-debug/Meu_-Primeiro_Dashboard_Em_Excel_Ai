# 📊 Meu Primeiro Dashboard em Excel + IA

## 📌 Sobre o projeto

Este projeto apresenta a criação do meu primeiro **Dashboard em Excel utilizando recursos de Inteligência Artificial (IA)** para organizar, analisar e visualizar dados financeiros de forma simples, prática e intuitiva.

O objetivo é transformar uma tabela de despesas em informações visuais que facilitem a compreensão dos dados e apoiem a tomada de decisões.

## 🎯 Objetivos

* Organizar dados de despesas pessoais;
* Utilizar o Excel para tratamento e análise de informações;
* Criar gráficos e indicadores;
* Desenvolver um dashboard visual e interativo;
* Explorar o uso da Inteligência Artificial como apoio na criação da solução;
* Facilitar a interpretação dos dados financeiros.

## 📁 Estrutura do projeto

O projeto contém:

* **Planilha Excel:** base de dados com despesas fictícias;
* **Dashboard:** visualização dos principais indicadores e gráficos;
* **IA:** utilizada como ferramenta de apoio para desenvolvimento e organização da solução.

## 📈 Informações apresentadas

O Dashboard permite visualizar informações como:

* 💰 Total de despesas;
* 📊 Distribuição das despesas;
* 📅 Análise dos gastos;
* 🏷️ Categorias de despesas;
* 📌 Principais indicadores financeiros.

## 🛠️ Ferramentas utilizadas

* Microsoft Excel
* Inteligência Artificial (IA)
* Gráficos e recursos de visualização de dados
